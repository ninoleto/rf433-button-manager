HTTPS certificate — download and setup instructions

HTTPS encrypts the connection. Because this certificate is created by your own server, each browser or device must trust it once. Downloading it alone is not enough.

Only trust a certificate from a server you control. Compare its SHA-256 fingerprint with the one shown when accessing the app directly on the server or through a trusted SSH/VPN connection. Do not rely on an untrusted HTTP page to verify itself.

The download contains the public CA certificate, never its private key. Keep this certificate only on devices you trust.

Windows — Chrome and Edge
  1. Save the certificate on your Windows PC. Press Win + R, type certmgr.msc and press Enter.
  2. Open Trusted Root Certification Authorities → Certificates. Right-click Certificates → All Tasks → Import.
  3. Choose the downloaded rf433-button-manager-ca.crt. Keep Trusted Root Certification Authorities as the destination. Review the certificate before accepting the trust prompt.
  4. Close and reopen your browser. Choose HTTPS above, apply and open the proposed address. Log in and select Confirm connection in Settings.
Linux — Chrome and Chromium
  1. Save the certificate on the Linux computer where you use the browser.
  2. Type chrome://certificate-manager into the browser’s address bar. Open Local certificates, then the Custom / Installed by you section. Under Trusted certificates, choose Import and select the downloaded file.
  3. Older browsers use chrome://settings/certificates: open Authorities → Import and enable trust for identifying websites. Do not import it as a personal/client certificate.
  4. Restart the browser, then open and confirm the proposed HTTPS address. If your browser or distribution has a different certificate manager, use its documented CA import procedure; do not bypass a warning.
Firefox — desktop
  1. Open Settings → Privacy & Security. Find Certificates → View Certificates → Authorities → Import.
  2. Select the downloaded certificate and allow it to identify websites after verifying it.
  3. Restart Firefox, then open and confirm the HTTPS address. Firefox may already trust the verified certificate installed in Windows or macOS.
Android — Chrome
  1. Download the certificate on your phone. In Android Settings, search for Install a certificate or Encryption & credentials (often under Security & privacy → More security settings).
  2. Choose CA certificate, verify the source, unlock the phone and select the downloaded file. Menu names vary by manufacturer; this is not a Wi-Fi or personal client certificate.
  3. Restart Chrome, then open and confirm the HTTPS address. Some managed devices and apps do not accept user-installed CAs. If trust still fails, use a supported browser or a certificate already trusted by your device; never skip the warning.
macOS — Safari and Chrome
  1. Open Keychain Access on the Mac and import the downloaded certificate into your login keychain.
  2. Open RF433 Button Manager local CA, expand Trust and allow trust for Secure Sockets Layer (SSL) after verifying its fingerprint. Save and authenticate if asked.
  3. Restart the browser, then open and confirm the proposed HTTPS address.
iPhone and iPad — Safari
  1. Download the certificate in Safari. Open Settings → General → VPN & Device Management (or Profile Downloaded) and install the certificate profile after checking its source.
  2. Go to Settings → General → About → Certificate Trust Settings. Enable full trust for RF433 Button Manager local CA.
  3. Reopen Safari and confirm the HTTPS address. If your device cannot install the certificate, use your device’s administrator or a certificate it already trusts; do not bypass warnings.

A changed server address, an expired certificate or importing into the wrong browser/profile can cause warnings. Match the exact address shown by the app. To remove trust later, remove only this app’s CA from the same certificate manager.

Renewal keeps the same trust certificate. You do not need to reinstall it.

Where do I find my token?

Open a terminal on the Linux computer running this app, or connect through SSH, and run:

sudo cat /var/lib/rf433-button-manager/management.token

Paste the printed token above. It is this app’s login token, not a Home Assistant token.

With a custom --data-dir, read management.token from that folder instead.

The token stays in this browser tab until you lock it or close the tab.
