Configuration backup

Backups include remotes, signal settings, webhook URLs and authentication headers. They exclude the login token, network access settings and HTTPS certificates. Restoring replaces the current remotes and settings; restored actions remain disabled for review.

Network & HTTPS

Choose how you connect to this app. These settings do not change Home Assistant, your firewall or router.

HTTP does not encrypt your token. HTTPS uses this app’s local certificate authority. Download its certificate and trust it on each PC or phone you use. Private keys stay on the server.

Open the proposed address, log in with your existing token, then confirm under Settings. If HTTPS is enabled, confirm using HTTPS. No token is included in these links.

How do I use HTTPS?

Download the trust certificate over your trusted current connection. Import it into the certificate store used by your PC or phone, then enable HTTPS and open the proposed address. Log in and confirm there. A download alone does not make your browser trust it. The private keys stay on the server.

Management token

Generate a new secure token if the current one was shared or lost. The old token stops working immediately in every browser. Your buttons and webhooks keep working.

You can always retrieve it on the server using the command on the login screen.

Where do I find my token?

Open a terminal on the Linux computer running this app, or connect through SSH, and run:

sudo cat /var/lib/rf433-button-manager/management.token

Paste the printed token above. It is this app’s login token, not a Home Assistant token.

With a custom --data-dir, read management.token from that folder instead.

The token stays in this browser tab until you lock it or close the tab.
