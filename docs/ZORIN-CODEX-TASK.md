# Archived installation handoff

This file was a task handoff for the original 0.1.0-dev installation. Its older
instructions and session-specific authorization are retired; they must not be
used to install, restart, access hardware or publish a later build. The original
text remains available in Git history.

For current work, start with [AGENTS.md](../AGENTS.md) and the
[developer guide](DEVELOPMENT.md). Use [OPERATIONS.md](OPERATIONS.md) for an
explicitly requested installation or recovery, [RELEASING.md](RELEASING.md) for
publication and [HARDWARE-TESTS.md](HARDWARE-TESTS.md) for actual hardware evidence.
The current user's instructions determine the authorized scope.
